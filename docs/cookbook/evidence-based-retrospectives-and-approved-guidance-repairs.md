# Recipe: Evidence-Based Retrospectives and Approved Guidance Repairs

## Problem

A retrospective can turn unverified impressions into organization-wide guidance. Repairs need transcript evidence, routed proposals, and approval before shared instructions change.

## Example

**Task:** Review a completed agent session and propose durable guidance repairs.

**AI Instructions:**

> 1. Collect the actual transcript, outputs, failures, and corrections.
> 2. Separate repeated patterns from one-off friction. Link each proposed repair to evidence.
> 3. Route accepted changes to the owning guidance file. List rejected ideas with reasons and unfinished work as backlog.
> 4. Present the complete accepted, rejected, and backlog lists.
> 5. Wait for explicit approval before applying shared guidance edits. Apply only the approved subset.
> 6. Keep an unrelated broken-skill repair in its own change. Record backlog work through the designated tracker when authorized.

## Best Practices

- Ground lessons in the session record.
- Preserve rejected and deferred findings.
- Treat approval for shared guidance as separate from retrospective analysis.
