# Recipe: Scoped Evidence Collection, Query Logs, and Contradictions

## Problem

Investigators can duplicate searches, follow unrelated sources, or select only evidence supporting a neat story. Without exact queries and contradictions, synthesis cannot distinguish missing evidence from an incomplete search.

## Example

**Task:** Collect evidence for the rationale behind a changed request limit.

**AI Instructions:**

> 1. Assign each investigator one source category and an explicit target, question, and scope; reserve final synthesis for a separate pass.
> 2. Search broadly within that source, then narrow. Read complete records, including comments and follow-ups.
> 3. Follow links only within the assigned source; record cross-source links as leads for the appropriate investigator.
> 4. Record queries verbatim, empty results, exact locations, and short accurately quoted evidence.
> 5. Preserve contradictory records and ambiguity. Do not infer intent from mechanics or substitute evidence about a different feature.
> 6. Return the evidence and leads without a final conclusion; let synthesis compare all records and label remaining uncertainty.

## Best Practices

- Separate collection from synthesis.
- Log exact queries and empty results.
- Preserve contradictions and source boundaries.
