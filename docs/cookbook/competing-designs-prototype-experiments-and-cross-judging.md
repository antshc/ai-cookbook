# Recipe: Competing Designs, Prototype Experiments, and Cross-Judging

## Problem

A team can commit to the first plausible design without comparing different shapes or measuring the disputed behavior. Prototypes need a decision and a common rubric.

## Example

**Task:** Compare three candidate interfaces for a new interaction before selecting one.

**AI Instructions:**

> 1. State the decision, constraints, and observable questions the experiment must resolve.
> 2. Build meaningfully different candidates from the same brief in isolated scratch outputs.
> 3. Use throwaway prototypes and the lightest stack that exercises the decision.
> 4. Measure the same behaviors and capture comparable evidence for every candidate.
> 5. After all candidates finish, ask an independent cross-judge to score them against the same rubric.
> 6. Choose the base from evidence and record why alternatives lost. Do not treat minor styling variants as different designs.

## Best Practices

- Use genuinely different candidate shapes.
- Freeze comparison criteria before judging.
- Keep experiments separate from production source.
