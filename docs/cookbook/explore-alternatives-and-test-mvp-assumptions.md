# Recipe: Explore Alternatives and Test MVP Assumptions

## Problem

An MVP can commit to the first appealing idea while its central assumptions remain untested. Alternatives need comparison against the same user problem.

## Example

**Task:** Refine an early product idea and choose the smallest useful MVP.

**AI Instructions:**

> 1. Name the intended user and the problem the product solves.
> 2. Generate several meaningfully different approaches before selecting one.
> 3. Compare each approach's user value, feasibility, cost, and failure risks.
> 4. Record the assumptions that could invalidate the preferred approach.
> 5. Choose a small test for each load-bearing assumption before committing to the MVP.
> 6. Converge on the evidence-backed option and record deferred scope.

## Best Practices

- Separate divergence from selection.
- Compare alternatives against the same user problem.
- Test assumptions before treating the MVP as settled.
